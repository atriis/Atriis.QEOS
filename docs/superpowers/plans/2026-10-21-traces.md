# Traces Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A failed result's Playwright trace reaches QEOS from CI and opens in the browser (stage 1 download, stage 2 self-hosted trace viewer); videos stay out (design section 8).

**Architecture:** Ingestion gets a streaming artifact endpoint next to ADR-036's image blobs (same `blobs` table with a `kind`, objects under `artifacts/{project_id}/`), a `result_artifacts` table (`kind = trace`), a project switch and its own retention days. The collector sends trace files named by Playwright JSON attachments or by a Cucumber reference attachment, streaming from disk. The dashboard downloads them, then (stage 2) opens Playwright's own trace viewer, built into the dashboard under `/trace-viewer/`, through a 60-second one-time link.

**Tech Stack:** ingestion-service (FastAPI, SQLAlchemy, Alembic, boto3, pytest), collector (stdlib, pytest), gateway (nginx template), dashboard (React, Vitest, msw, Vite), OBT (cucumber-js hook).

**Spec:** `docs/superpowers/specs/2026-10-21-traces-and-videos-design.md` (traces only; section 8 videos is out of scope)

## Global Constraints

- Trace media type `application/zip` only; magic bytes `PK\x03\x04`; at most 100 MB per trace; at most 5 traces per result, 500 per run.
- Object key `artifacts/{project_id}/{sha256}`; `blobs.kind` = `screenshot` (default, existing rows) or `trace`.
- Project settings: `keep_traces` (off by default), `trace_days` 1-90 (default 14). Settings text (exact): "Traces contain page snapshots and network traffic, which can include cookies, tokens and personal data of your test accounts. QEOS cannot mask them. Turn this on only if every project reader may see that."
- Key check field `artifacts: true|false` (true when storage is configured and `keep_traces` is on).
- Collector 0.14.0: `--no-artifacts`, `QEOS_NO_ARTIFACTS=1`, `no-artifacts: true` in `.qeos.yml`; upload budget 300 s, 2 at a time; files read only inside the working directory (0.13.0 rules) and streamed from disk.
- Cucumber reference attachment media type `application/vnd.qeos.artifact+json`, content `{"kind": "trace", "path": "..."}`; `"video"` is skipped and counted.
- One-time links: random 32-byte token, stored as SHA-256, valid 60 s, bound to artifact id, user id and client IP; the trace viewer may make several GET/Range requests within the 60 s.
- Trace viewer: Playwright's `playwright-core/lib/vite/traceViewer`, version pinned in `dashboard/package.json`, served from the same origin at `/trace-viewer/`; never `trace.playwright.dev`.
- QEOS: commit to master with explicit paths; push only at the plan's push points after CI-equivalent checks; every behaviour commit updates the affected docs. OBT: branch `qeos/traces` + PR only.

## Review Focus

1. **A trace upload cut off mid-stream or with a wrong SHA-256**: nothing stays in MinIO or `blobs` (test in Task 2).
2. **A project switches `keep_traces` off while a run is uploading**: PUT answers 403, the run still uploads without `traces` (tests in Tasks 2 and 4).
3. **A one-time link reused after 60 s, from another IP, or for another artifact id**: 404, no bytes (test in Task 7).
4. **Retention when `trace_days` < result retention**: traces go, results stay; the trace blob is garbage-collected after 7 days unreferenced (test in Task 3).
5. **A Cucumber reference pointing outside the working directory or at a non-zip file**: skipped and counted, the run uploads (test in Task 4).

**Interfaces — Produces:**
